How to participate

RULE 01

Reuse before inventing

Start from the existing node library and its fossil-bed atlas. Add a new node only to fill a real gap.

RULE 02

Make interventions visible

A wired port must be live. An animated result is not enough: test negative controls, timing, and causality.

RULE 03

Preserve the evidence

Save graphs, code, metrics, mistakes and provenance. Contributors work on branches and submit reviewed proposals.

Full policies: workshop contribution rules and collaboration guide.

The first completed cycle

EXPERIMENT 001 · CAUSAL-AGE READOUT

When does a propagating field carry useful information about the past?

We connected the existing PulseSource and WaveField to a small online predictor. The predictor compared an earlier near-field observation against a simultaneous baseline, without rewriting the wave physics.

  • Original research and reproducible tests
  • Merged PerceptionLab contribution #1
  • Reusable saved graph
ONE HEADLESS SIMULATION RUN

+11.89 dB

Mean rolling delayed-prediction advantage over a simultaneous readout. Six automated checks passed, including the zero-delay control.

This establishes neither autonomous material learning nor biological memory. The interactive GUI graph was not itself part of the measurement.

What can you build?

Combine a cochlea with an oscillator. Probe how a wave field changes a logic gate. Connect a memory to a living substrate. The point is to test the interaction, not merely display it.
